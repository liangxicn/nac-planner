# NAC 布线工作台

双击 `index.html`，用 Edge、Chrome 或 Firefox 打开即可。网页不依赖服务器、联网资源或安装步骤。

## 操作

画布下方可切换“查看模式 / 连线模式”，默认连线模式，选择会记住。查看模式可点击查看模块和线路信息、拖动画布与缩放；不会添加、移动、连接、替换或删除模块／线路，属性编辑、撤销重做、导入和重置也暂时禁用。连线模式恢复全部编辑操作。

- 左键空槽位：选择模块。共 11 种模块，同类可重复摆放。每个模块每边最多 5 个接口，四边独立、不共用角落，共 20 个接口；输入与输出合计，自连回路占两个接口。新建连线时满边会尝试其他边；拖动接口不能进入已满的边。
- 左键模块或控制室：选起点；再点另一台建立有向连线，再点自己建立独立回路。
- 左键拖动模块：移到空槽位，或与已占用槽位交换。中央控制室固定。新增或移动模块挡住已有线路时，会自动重新绕线，保留原来的连接对象、接口、颜色和备注；无法无交叉绕开时取消这次放置，避免留下重叠。模块操作与自动绕线可一起撤销。
- 右键：已有模块或线路选中时，取消选中（也可取消正在发起的连线）。没有选中项时，右键模块打开替换菜单，可选择是否保留关联线路。
- 控制室连线：直接点击小接口，再点目标模块；或先点模块，再点控制室的目标接口。点边框也可选取最近接口，不弹出选边框，不自动换位。占用的接口不能重复连接。没有起点时点击已占用接口，可以选中它的线路。每边 7 个接口位置，四角共用，共 24 个独立位置；接口仍可拖动换位。
- 点击线路：显示接口和线段把手。控制室和模块的接口都显示为可拖动圆点。拖短把手调整直角走向；模块与控制室内部禁止穿线，自动布线会绕开模块。横线接近模块上下边、竖线接近左右边时会吸附到边框（10 屏幕像素内），松手后保留贴边位置。两端接口仍附着于对应边框。穿入模块或与其他线路交叉、重叠的拖动会被阻止。
- 右侧面板：改线色、填写备注、置顶/置底、重新布线或删除；选中模块后可改名和删除。
- 点击空白或 Esc：取消选择。Delete：删除当前线路或模块。Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做。
- 拖动空白：平移。滚轮或顶部按钮：缩放。点击缩放百分比：恢复全图。
- 工具栏“重置”：清空模块和线路，恢复初始视图，保留平行吸附偏好；可立即撤销恢复布局。

## 保存

布局会自动保存在当前浏览器的本地存储中。换浏览器、换文件路径或清除浏览器数据后，不一定保留；用“导出方案”保存 JSON 备份，再用“导入方案”恢复。导入也能撤销。

## 布局说明

12 个平台中心按 GT5-Unofficial 的 `AssemblyComplexStructureString` 内 F 控制器位置归并得到，使用下列 X/Z 坐标（以 31,31 为中央参考）：

`(23,8), (39,8), (48,14), (54,23), (54,39), (48,48), (39,54), (23,54), (14,48), (8,39), (8,23), (14,14)`

槽位 01–12 是本工具顺时针编号。模块卡片和控制室采用可读性优先的示意尺寸，不表示逐方块占地或真实接口合法位置。

模块、空槽位和控制室均为正方形边框。线路优先采用直线或只转一次弯的 L 形路径；无法直接连接时才绕行。拖动接口后重新尝试简洁路径，拖动线段后清除多余的共线折点。直线仅保留两个端点和一个线段把手。拖动完整直线时，整条线和两端接口一起沿边平移，不会在中间额外生成台阶。控制室与模块之间的折线也支持联动：两端接口所在边允许同向滑动时，拖线可带动两端与原有折线整体移动；拖中间线段沿接口可滑动的方向移动也适用。控制室端仍吸附至固定接口位，超出边框范围、接口被占用或与其他线路冲突时不会强行移动。工具栏的“平行吸附”默认开启，可临时关闭，选择会保存在本机。仅在手动拖动靠近或松手时，同一条线路内相距不超过 14 个画布单位的小折返会尝试吸附整理；可行时对齐模块接口并拉成直线，保留控制室接口位置，并播放轻微的弹性反馈。新建线路、切换开关、导入或刷新方案不会自动对齐接口或拉直已保存的折线。不同线路即使同色也不会被合并，自回路不会被压成直线。仍会避开已有线路和模块内部；可以贴着模块边框走线。新连线的默认方向被阻挡时，会继续尝试模块四边的可用接口，允许从所有模块和已有线路外侧绕行，寻路不受画布可视范围或连接距离限制。控制室的点选接口保持不变。尝试外围和其他模块接口后仍找不到无交叉路径，才提示调整已有线路。该工具采用逐条寻路，提示无路径表示当前端点与既有走线下未找到路径，不意味着所有重新布局方案都不可行。

同一模块对可有多条线；模块接口和折线仍可手动调整。自连回路默认位于远离中央控制室的一侧，独立于普通连线的排列。

模块移动/交换时关联线路会重新寻路，保留颜色和备注；若无法保持无交叉则取消移动。自动自连回路随新槽位重新朝向外围；手动回路优先整体跟随。拖动模块接口会重新生成该线路的折线。所有这些操作均支持撤销。

首次读取旧版布局时，会在浏览器本地存储保留一份更新前备份，再适配正方形尺寸和固定接口。旧方案中无法自动排成无交叉路径的线路会保留记录，在右侧标为“待调整”，暂不画出；调整布局后选择该线路并点击“重新布线”，或删除后换边重建。旧版方案超过 24 个控制室接口时会拒绝转换并保留原存储。

当前仅规划模块与线路，不模拟配方、物料、电力或实际管道层高。不设置模块朝向，线路箭头只表示运输方向。

## 双层布线

底部“第一层／第二层”切换当前布线层；新线路属于当前层。另一层半透明显示且不能直接拖动，第二层的线和把手以 4 个画布单位的轻微偏移区分，逻辑走线位置不变。点击右侧线路记录会切换到该线所在层。查看模式也能切层。

每层独立避让线路，两层可互相跨越；模块阻挡与接口容量仍然共用。旧方案中未标注层的线路视为第一层，保存、导入导出、撤销重做均保留线路层信息，当前层偏好保存在本机。

## 模块配方与运输物品

配方来自 GTNH 2.9.0 RC2 dump，recipe-data.js 内置 10 类加工模块、148 条配方与 246 个物品的中文名称，离线打开无需加载外部文件。显示仅包含物品输入 → 输出，不含数量、流体；可替代输入用 / 表示，多项必需输入用 ＋ 表示。

点击模块，在右侧生产配方列表中搜索、勾选多个配方（再次点击取消，支持清除全部）；点击线路，从终点所选全部配方的输入并集中勾选多个运输物品。终点为控制室时，从起点所选全部配方的输出并集中选择。模块改选配方保留已有运输物品并显示不匹配提示；替换模块会清空模块配方及全部相连线路的运输物品。新增菜单暂不提供纳米组件分流器，已有存档中的分流器仍可显示和替换。

颜色检查按 GT5-Unofficial e36e0dd726ed8f95b64213014f4ec0f468b8e199 的 MTENanochipAssemblyModuleBase.ItemInputInformation.getPrimaryColor（不启用输入分离）处理：加工输出跟随配方首项输入的颜色。缺失首项输入线路时提示待检查，颜色不匹配时提示，不自动改色。当前不模拟输入分离模式、产量和流体。配方与运输物品随布局保存、导入导出及撤销重做。查看模式下可搜索配方但不能修改选择。

多选配方保存为 recipeIds，兼容旧版 recipeId 单选记录。线路候选物品去重；输出颜色仅对照能产出该物品的已选配方，不与无关配方混合校验。

线路运输物品支持复选、搜索、清除全部；保存为 itemIds，兼容旧版 itemId。配方与进出颜色按每种物品分别检查，不匹配的已选物品保留待调整标记并可取消；更换模块清空相连线路的新旧物品字段。

选择或取消线路运输物品时，自动比较起点模块相应配方首项原料的已标注入线颜色：共同可用颜色唯一时自动改色，当前颜色已符合则保留。起点未选配方时可从其全部配方匹配输出。找不到完整上游信息时保持原色并提示，多物品颜色冲突提示拆线，多种可用颜色提示手选。控制室出线不自动改色；物品和自动颜色作为同一步保存与撤销。

超导线束分离器的生产配方只能选一种；点选另一种会替换原选择。旧存档若有多种超导配方，读取时保留记录中的第一种，其余运输物品仍保留并按现有规则提示待调整。

运输物品旁和线路列表增加小色块。模块出线的同一种物品有多种上游颜色可选时，候选按颜色展开：原名、原名*（更多颜色继续加星号），选择候选即选择对应线色。同一线路仍只能使用一种颜色。星号仅为网页显示标记，内部物品 ID 与配方不变；标记按当前颜色集合排序生成，不模拟游戏中的铁砧自定义命名。

右侧调色板改色会同时修改通过配方首项原料关联起来的上游/下游运输链，在改色前按物品和原颜色识别通道。控制室作为边界，不会因共用控制室而合并其他线；不同颜色的同物品支路独立。已错色的线段若只有一种对应上游颜色，也可纳入同步修正。未标注物品或来源存在多种颜色歧义时不会猜测关联；联动改色作为一步保存和撤销。

新增或移动模块时，除了穿过内部的线，也会检查距新边框 8 个画布单位内的线（包括贴边线），并在两层分别重新绕行，保留端点、颜色与运输物品。该避让留白仅用于模块放置引发的重排，普通连线与手动贴边不受影响；添加与线路调整可一步撤销。若无法保持既有端点及同层无交叉，则仍取消此次放置。

密集布线下，新增模块的局部绕行若失败，会继续尝试将受影响层的线路一起重排，并尝试不同布线顺序；先计算整组结果再提交，保留端点、层、颜色和物品。多段线会一并让出空间；仍无法完成时整体恢复原布局。

自动连线的通道优先级：模块与模块之间，先尝试朝外接口并沿 12 槽位外围走线（空槽位也纳入外圈范围）；控制室与模块之间，先尝试模块朝内接口及内部通道，控制室点选的接口保持不变。首选通道被挡住或接口容量不足时，回退到其他合法走法。同层仍不交叉，跨层分别寻路。此规则用于新建线路和“重新布线”，打开旧布局不主动改线，手动接口和折线仍可调整。

新增/移动模块触发的弹开与联合重排，同样先尝试模块间外圈、控制室连接内圈。该阶段固定原有接口，在其约束下首选通道不可行时回退普通绕行；不改变颜色、运输物品和层。

拖动已有折线的接口且仍在原边时，优先仅移动端点及紧邻折点，保留远处的绕行形状；局部调整碰撞则恢复，不重新挑选模块另一侧的捷径。模块间线路的首末线段支持沿接口所在边一起滑动，不再只挪动中间一小段。换到另一接线边仍按新接口寻路。
